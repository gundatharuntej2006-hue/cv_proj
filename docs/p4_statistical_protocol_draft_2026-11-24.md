# P4 statistical protocol draft — 2026-11-24

**Status:** P4-owned prospective draft for team review. It does not certify the legacy D21 record, approve a sealed evaluation, or backdate a decision.

## Detector preprocessing comparison

P4 selects **2,000 paired bootstrap replicates and master seed 42** for the four-candidate P3 detector preprocessing study. The comparison uses a **derived seed**, not 42 directly: let `analysis_id = "p3_detector_preprocessing_v1"`, encode `"D21:v1|42|" + analysis_id` as UTF-8, compute SHA-256, and interpret the first four digest bytes as an unsigned big-endian integer. Initialize NumPy `Generator(PCG64(derived_seed))` once for the study. This fixed identifier gives all three ordered candidate comparisons the same resampling plan. A different prospective analysis must have a distinct, recorded analysis ID.

Use the same reviewed development image IDs and original full-512 lesion annotations for every candidate. Sort the unique image IDs lexicographically within TB and non-TB strata. For each of 2,000 replicates, draw with replacement the original stratum size from each stratum in TB then non-TB order. Save the complete draw sequence as UTF-8 CSV with LF newlines and columns `replicate,stratum,draw_position,image_id` (zero-based replicate and position; stratum is `tb` or `non_tb`). Order rows by replicate, then TB before non-TB, then draw position. Record the file's SHA-256 in the report and D24 evidence. All candidates must consume this exact index file; no candidate may regenerate its own draws. Recompute both AP50 values using the same sampled IDs and multiplicities, and store `AP50(candidate) - AP50(current)`. The 95% percentile interval is the 2.5th and 97.5th percentiles of these 2,000 paired differences.

If any point estimate or bootstrap replicate is non-finite, stop the comparison and mark it invalid. Record the count and affected replicate IDs for diagnosis; correct the input or metric and rerun the complete study with the same approved protocol. Do not drop non-finite replicates, renumber draws, or report an interval from a subset. The D21 conformal `alpha=0.10` is distinct from the `ci_level=0.95` here.

Start with full image/CLAHE off. Visit full image/CLAHE on, 0.10 crop/CLAHE off, then 0.10 crop/CLAHE on. Promote a candidate only if its unrounded AP50 point difference is at least 0.01 **and** the paired interval's lower endpoint is strictly above zero. Otherwise keep the current simpler choice. Record every candidate's AP50, all three ordered comparisons, image and lesion counts, replicate count, seed, input hashes, run IDs, and promotion decisions. This rule selects a development configuration; the nominal 95% intervals are not a multiple-comparison-adjusted claim of superiority.
